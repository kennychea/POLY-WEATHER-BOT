# P7.4 — Precipitation Ensemble + Market Parsing

## Objective
Add precipitation forecasting to the ensemble pipeline and parse Polymarket rain/snow markets.

## Changes

### weather/ensemble.py
1. In `fetch_ensemble()`: accept `variables` param (default: `["temperature_2m"]`)
   - For precip: `["precipitation"]` (Open-Meteo hourly variable name)
2. When `precipitation` requested: compute daily sum per member (not max/min)
   - Return key: `precipitation_total` (list of member daily totals in mm)
3. Add `fetch_precipitation_ensemble()` convenience wrapper
4. In `fetch_multi_model_result()`: accept `metric` param and route to correct variable
   - `"temp_high"` / `"temp_low"` → temperature_2m (existing)
   - `"precip"` → precipitation (new)

### weather/market_scanner.py
1. Add precipitation parsing patterns:
   - "Will it rain in {city} on {date}?" → threshold "precip" > 0.0 mm
   - "Will precipitation in {city} exceed {X} inches on {date}?" → threshold "precip" > X
   - Slug: "rain-" or "precipitation-"
2. Handle unit conversion: Open-Meteo returns mm, Polymarket may quote inches
   - 1 inch = 25.4 mm
3. New metric: `"precip"` added to `ParsedWeatherMarket.metric`

### weather/probability.py
- No changes needed — `ensemble_probability()` already handles threshold direction

## Open-Meteo Variables Reference
- `precipitation` — hourly precipitation in mm (rain + showers + snowfall water equivalent)
- Available in all 3 models (GFS, ECMWF, ICON)

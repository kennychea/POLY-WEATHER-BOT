# P7.2 — Skill-Weighted Model Averaging

## Objective
Replace equal-weight averaging in `multi_model_probability()` with configurable skill-based weights. ECMWF gets more influence than GFS/ICON.

## Changes

### infra/config.py
1. Add field `model_weights: dict[str, float]` to Config
2. Default: `{"ecmwf_ifs025": 0.5, "gfs_seamless": 0.3, "icon_seamless": 0.2}`
3. New env var: `MODEL_WEIGHTS` — JSON string override, e.g. `'{"ecmwf_ifs025":0.6,"gfs_seamless":0.4}'`
4. Parse in `from_env()`: `json.loads(_get("MODEL_WEIGHTS", ""))` or default

### weather/probability.py
1. Update `multi_model_probability()` signature: add `weights: dict[str, float] | None = None`
2. If weights provided: weighted average instead of simple mean
   ```python
   total_weight = 0.0
   weighted_sum = 0.0
   for model_name, members in model_members.items():
       w = weights.get(model_name, 1.0 / len(model_members))  # fallback = equal
       prob, _ = ensemble_probability(members, ...)
       weighted_sum += prob * w
       total_weight += w
   avg_prob = weighted_sum / total_weight  # auto-normalizes
   ```
3. If weights=None: keep existing equal-weight behavior (backward compat)
4. Confidence: same spread + disagreement logic, but weighted disagreement

### main.py
1. Pass `cfg.model_weights` to `multi_model_probability()` call in `_evaluate_market()`

### weather/cli_scanner.py
1. Pass default weights to `multi_model_probability()` call in `analyze_edges()`

## Tests
- `test_weighted_probability_ecmwf_dominant`: ECMWF=1.0, GFS=0.0 → prob matches ECMWF only
- `test_weighted_probability_equal`: all weights equal → same as simple average
- `test_weighted_probability_missing_model`: 2/3 models → weights normalize
- `test_config_model_weights_parsing`: env var → dict
- `test_config_model_weights_default`: no env var → default weights

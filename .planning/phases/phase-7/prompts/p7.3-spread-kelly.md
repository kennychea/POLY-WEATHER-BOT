# P7.3 — Spread-Based Confidence → Kelly Adjustment

## Objective
Use ensemble member spread (standard deviation) to modulate bet size. Tight consensus = bigger bet. Wide disagreement = smaller bet.

## Changes

### weather/probability.py
1. New function: `compute_spread_score(model_members, weights=None) -> float`
   - Per model: `std_dev = statistics.stdev(members)` (or pstdev for population)
   - Max possible std for temperature: ~30°F (heuristic, configurable)
   - Per-model score: `max(0, 1.0 - std_dev / max_std)`
   - Weighted average of per-model scores using same weights as probability
   - Return clamped to [0.3, 1.0] — floor of 0.3 prevents zero-sizing
2. Update `multi_model_probability()` return: `(prob, confidence, spread_score)`
   - Backward compat: callers that destructure 2 values need updating

### infra/types.py
1. Add `spread_score: float = 1.0` to `EdgeResult`

### core/edge_calculator.py
1. Add `spread_score: float = 1.0` param to `calculate_edge()`
2. Pass through to `EdgeResult`

### core/risk.py
1. In `size_position()`: accept optional `spread_score: float = 1.0`
2. After Kelly calculation: `size *= spread_score`
3. Log: `"Kelly size $%.2f adjusted by spread %.2f → $%.2f"`

### main.py
1. Capture `spread_score` from `multi_model_probability()` return
2. Pass to `calculate_edge()` and `risk_manager.size_position()`
3. Log spread_score in TRADE_SIGNAL line

### weather/cli_scanner.py
1. Capture and display `spread_score` in verbose mode

## Tests

- `test_risk_sizing_with_spread`: verify size * spread_score
- `test_multi_model_probability_returns_spread`: 3-tuple return

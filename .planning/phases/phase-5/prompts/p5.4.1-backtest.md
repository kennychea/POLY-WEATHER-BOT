# P5.4.1 — Backtest framework with calibration metrics

You are working on a Polymarket weather arbitrage bot. Read `tasks/lessons.md` first. Read `.planning/phases/phase-5/PLAN.md` section P5.4.1 for full details.

## Prerequisites
P5.2.2 must be done (real resolution with proper calibration logging).

## Task
Create a backtest module that analyzes resolved trades: hit rate by confidence, edge accuracy, Brier score, edge correlation. CLI: `python -m weather.backtest`

## Files to create/modify
- `weather/backtest.py` (new) — BacktestResult, compute_brier_score, compute_edge_correlation, run_backtest, format_report, CLI entry
- `infra/db.py` — add read_calibration_log() if not present
- `tests/test_backtest.py` (new) — 8 new tests

## Steps
1. Read `infra/db.py` to check if read_calibration_log() exists, add if missing
2. Create `weather/backtest.py` with:
   - BacktestResult dataclass (total_trades, win_rate, pnl, brier_score, confidence breakdown, edge correlation)
   - compute_brier_score(predictions, outcomes) — mean((p - o)^2), lower is better
   - compute_edge_correlation(predicted, realized) — Pearson r
   - run_backtest(db_path) — async, reads calibration_log, computes all metrics
   - format_report(result) — human-readable ASCII report
   - CLI __main__ block: `python -m weather.backtest [db_path]`
3. Confidence bucketing uses numeric values from calibration_log:
   - >= 0.7 → "high", 0.3-0.7 → "medium", < 0.3 → "low"
   - (P5.2.2 maps high/medium/low strings to 0.9/0.5/0.2 during logging)
4. Write tests: brier perfect/random/empty, correlation perfect/uncorrelated, empty DB, seeded DB, format output
5. Run `python -m pytest tests/test_backtest.py -v` — all pass
6. Run `python -m weather.backtest` — runs without error
7. Run `python -m pytest tests/ -v` — 0 regressions

## Constraints
- Pure math, no LLM in the hot path
- Must work with empty DB (return zeroed BacktestResult)
- Use pathlib.Path for db_path
